# 功能清单

> 讲什么：当前已实现的能力，按视图与功能域汇总。实现位置见 [SYSTEM](SYSTEM.md)，日志链路见 [DATA-FLOW](DATA-FLOW.md)。

## 日志聚合

| 能力 | 说明 |
| --- | --- |
| 尾部加载 | 按设置拉取文件尾部 N MB、最多 N 行；截断时丢弃首行残片，状态栏显示大小与截断提示 |
| 虚拟滚动 | 可变行高，自动换行也只渲染可视区与前后缓冲行；滚动位置按比例保持 |
| 长条目折叠 | 单条日志视觉行数超阈值时插入折叠条，正文不截断，可展开 |
| 上下文弹窗 | 点击日志行按原始行号取前后行，滚动到边界时懒加载；筛选状态下也能看到被隐藏的周边行 |
| 过滤 | 芯片式包含 / 排除条件，按整条日志匹配；支持编辑、模式切换、历史回填（最多 15 条）与过滤后行数反馈 |
| 独立高亮 | 回车逐条添加高亮词，整串匹配（可含逗号、空格），只染色不过滤、不隐藏行 |
| 查找定位 | 显示「第 n/N 处」，上一处 / 下一处循环跳转，滚动到命中行并标记当前行；命中在折叠条目内先展开 |
| 历史文件 | 按日期筛选后只列该日期归档（不混入「当前」活跃日志），并默认打开该日期最新滚动序号的归档；未筛选时显示活跃标记，另有文件数、索引刷新时间与强制全量探测 |
| 搜索工具抽屉 | 过滤、高亮、查找、历史文件四区合一；可固定常驻，未固定时点击外部或切走视图自动收起 |
| 常用操作 | 自动换行、自动滚到末尾、重新加载、复制全部 / 过滤结果 |
| 整文件下载 | 流式读取并保存为 Blob，带进度、可取消；文件名按「中文环境标签_项目展示名_级别.log」生成，如「测试环境_订单服务_INFO.log」；环境取配置里的 `label`，缺失回退环境 key |

三层高亮互不干扰：过滤词 `hit`、独立高亮 `hl`、查找词 `find-hit`，当前命中行另有整行标记。

## 仪表盘

- 环境切换与模块列表，展示各服务的级别。
- 手动探测级别（有限并发、批间抖动），索引按日软刷新。
- 打开指定级别日志、下载整文件（自动带上中文环境名与项目名）、复制链接。
- 级别按钮显示当前日志文件大小（目录列表自带，探测级别或按日软刷新后自动出现）。

## 访问统计（可选）

- 在线会话与操作事件（打开视图、切换环境、打开日志、下载、复制、查看上下文等）。
- 统计页提供在线、近期事件与汇总；仅白名单 IP 可查询，**不记录日志正文**。详见 [ACCESS.md](ACCESS.md)。

## 设置

- **外观**：暗黑 / 明亮 / 暖色三套主题预设，以及完整颜色网格。
- **字体与排版**：日志字体、字号、行高。
- **阅读与加载行为**：`maxLines` / `tailMB`、自动换行、自动滚到末尾、折叠阈值、上下文窗口参数。
- **配置导入导出**：勾选服务配置、访问统计、主题与设置、文件名索引、过滤历史、界面状态打包为单个 JSON；导入先预览归档版本与将覆盖的内容，逐项勾选后才写入。服务配置需统计白名单权限，写回前在 `backup/` 生成备份；代理凭据（`.env`）不入归档。
- 偏好草稿在页面内修改，点「保存设置」才写入并生效；改动加载上限时自动按新限制重新拉取日志。配置分区独立于草稿，自成一套流程。

## 横切能力

| 能力 | 说明 |
| --- | --- |
| 地址栏同步 | 视图、环境、服务、级别与文件写入 URL，刷新可还原 |
| 主题与 token | 三套主题共用语义变量，组件不写死颜色 / 圆角 / 阴影 / 过渡 |
| 请求编排 | 超时、按调用方独立取消、同键进行中请求共享、错误体解析 |
| 短期正文缓存 | 内存 LRU，60 秒 / 12 份；强制刷新、切换文件与改加载上限会回源 |
| 大日志处理 | ≥2500 行走常驻 Web Worker，分组与搜索索引只构建一次，后续只发查询 |
| 视图保活 | 四个视图用 `keep-alive` 缓存，切走再回来不重建 |
| 配置归档 | 单文件导入导出服务配置与本地偏好；白名单校验、服务端备份、导入前预览与逐项确认；导入即生效（自动重载本地状态，不再需要刷新页面，也不提示「未保存」） |
| 版本更新检查 | 页面加载时读取 GitHub 最新 tag 并与本地版本做语义化比较；1 小时缓存、请求去重、网络不可达静默降级，有新版本时侧栏版本号旁显示可点击提示 |
