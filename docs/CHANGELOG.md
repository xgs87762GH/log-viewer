## v1.0.2

搜索工具区与文档体系升级：

- 顶部收敛为一行主工具条 + 可固定 / 可自动收起的**搜索工具抽屉**，四个分区：过滤、独立高亮、查找、历史文件；未固定时点击外部或切走视图自动缩回。
- 独立高亮改为**回车逐条添加**的词条，整串匹配（可含逗号、空格），自绘胶囊样式，与过滤词、查找词状态隔离。
- 新增查找定位：基于过滤后可见行显示「第 n/N 处」、循环跳转、滚动到命中行并标记当前行；折叠条目内的命中先展开。
- 三层高亮（过滤 `hit` / 高亮 `hl` / 查找 `find-hit`）与对应全局样式，高亮 HTML 缓存键扩展。
- 新增纯函数与用例：`logFind.js`、`highlightTerms.js`、`toolDrawerState.js` 及三组测试。
- README 收敛为总览与文档索引，`docs/` 拆成架构、功能、设计、数据链路、访问统计、变更记录六篇，统一简体中文并同步当前代码事实。

发布前验证：前端构建、**61/61** 单测、`py_compile`、lint、57 个文档相对链接，以及暗黑 / 明亮双主题与自动收起行为的无头浏览器核对均通过。

## 已知限制

- 日志正文**不落盘**，只在浏览器内存保留 60 秒、最多 12 份；刷新页面即丢失。
- `ETag` / `Last-Modified` 只记入缓存 meta，代理未转发上游这两个头，条件请求尚未启用。
- 上下文弹窗只读已加载的尾部数据，更早的行不联网补拉；按字节区间拉取列为后续方向。
- 整文件下载的 Range 分片 / 断点续传为预留设计，尚未实现。
- 日志正文无轮询；统计页与在线心跳有自己的定时器。
- 三套主题下日志正文区保持独立深色色板（设计选择）。

## 后续方向

- 打通条件请求（`ETag` / 304）与缓存 meta，减少重复传输。
- 上下文按需按字节区间补拉，解除「只有尾部」的边界。
- 后端传输升级；正文是否允许持久化需先确认再评估。
- 继续收敛大日志下的过滤与渲染耗时。
